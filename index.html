Smart Solutions for a World Crisis

Enhancing the Extinction Solutions Index (ESI) with Natural Language Processing (NLPs) & Large Language Models (LLMs)

A visual reminder of what's at stake — imagine a world without these species.

Quick overview

This project builds an AI-enabled pipeline to gather, synthesize, and rank conservation solutions around the world using semantic search and a retrieval-augmented LLM. The aim is to support the Extinction Solutions Index (ESI) by making verified solution information searchable and comparable for conservation practitioners and policymakers.

The prototype focuses on agricultural pollution so, all the conservation solutions pertain to reducing nutrient runoff and improving freshwater biodiversity outcomes.

The conservation problem

Species globally are at risk from drivers like land-use change, pollution, climate change, invasive species, and direct exploitation. There is an urgent need to compile and synthesize solution evidence so practitioners can scale effective interventions quickly and equitably.

How this supports CXL’s mission

Provides an operational, research-grade tool to identify high-impact conservation strategies, streamline evidence synthesis, and support data-driven decision making across ESI priorities.

Role of AI

AI (NLP + LLMs) automates extraction of intervention details, costs, outcomes and context; semantic search enables rapid retrieval that is grounded in evidence.

About the Project

Project Context

Biodiversity loss is accelerating and conservation evidence is scattered across papers, reports, and gray literature. This project demonstrates how NLP and LLMs can ingest heterogeneous text sources and surface evidence about interventions that reduce extinction risk.

Why the ESI needs this

The Extinction Solutions Index benefits from automated, scalable methods to gather comparable metrics (e.g., potential STAR contributions) across interventions so ESI can recommend scalable, high-impact solutions.

Project Overview

Problem statement

The global challenge: species extinction is driven by multiple interacting threats. There is no single, scalable repository that synthesizes evidence on actionable interventions and their likely conservation impact. Practitioners need accessible, trustworthy summaries to prioritize interventions.

Why LLMs

LLMs accelerate reading and summarizing of unstructured text, while semantic search via embeddings allows retrieval of the most relevant portions of documents. Together, they enable a fast, evidence-grounded response to practitioner queries about interventions.

Project Goals

  • Use LLMs + semantic search to organize and retrieve conservation solutions.
  • Build a pipeline that evaluates outputs using the STAR metric.
  • Produce a reproducible prototype and documentation for CXL integration.

Timeline (Spring → Summer)

Spring Proposal, literature review, prompt design, data scoping.

Summer Embeddings & FAISS setup, RAG pipeline, STAR evaluation prompts, case study (precision agriculture), testing, and demo.

Key research questions

  • How can AI organize conservation solutions efficiently and transparently?
  • How can STAR metric components be integrated into prompts to produce ranked outputs for places + threats?
  • How well does the pipeline perform on a case study (precision agriculture) compared to domain expectations?

Methods & Workflow

Data preparation

Sources compiled: peer-reviewed articles, technical reports, NGO field reports, and ESI-curated solution summaries. Key items extracted per document: intervention type, geographic context, reported outcomes, costs (if available), and metrics of biodiversity response.

Embedding strategy: OpenAI text embeddings (e.g., text-embedding-3-small) were used to vectorize passages; chunking parameters tuned to balance context vs. retrieval precision (note: you had an issue where only 4 chunks appeared — TODO to inspect chunking/overlap settings).

Vector DB & semantic search

FAISS local index was selected for fast, offline similarity search during prototype development. Documents were split into overlapping chunks, embedded, and stored with metadata (title, source, year, location tags).

LLM integration & prompt engineering

A Retrieval-Augmented Generation (RAG) pipeline uses a reformulation prompt (to create standalone questions from chat history), a retriever (FAISS), and a document-combining chain to feed retrieved context into the LLM with concise answer constraints. Special prompts were built to compute / assemble STAR metric inputs for each candidate solution.

Results, Insights & Reflection

Functional achievements

  • Configured FAISS index and embedding pipeline.
  • Built a RAG pipeline (reformulation prompt + retrieval + LLM answer chain) and tested with precision agriculture case queries.
  • Created prompts and scaffolding to compute STAR metric components per candidate solution (needs IUCN species-per-location and %restorable-AOH data to fully compute).

Case study — Precision Agriculture

Example: Query — "Which precision agriculture interventions reduce nutrient runoff and benefit freshwater species?" → Pipeline retrieves intervention studies, summarizes the evidence (reduction in fertilizer use, measured water quality outcomes), and estimates STAR-related contributions based on available metadata.
